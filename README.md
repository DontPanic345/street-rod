# Street Rod '63

An unofficial browser tribute to *Street Rod* (California Dreams, 1989).

**Play:** https://dontpanic345.github.io/street-rod/

It's summer 1963 in Paloma Valley. Buy a junker from the classifieds, soup it up at Hal's Speed Shop,
and race your way up the ladder at the Tip-Top Drive-In. You can drag race at the old airstrip or run
Devil's Canyon Road. Take The King's pink slip before Labor Day.

## Controls

| Key | Action |
| --- | --- |
| ↑ / W | Gas (drag: hit it on the green) |
| ↓ / S | Brake |
| ← → / A D | Steer |
| Space / E | Shift up |
| Q / Z | Shift down |
| P | Pause |
| M | Mute (in menus) |

Menus have number hotkeys. Phones get on-screen controls.

## Running locally

No build step. It's plain ES modules, so serve the folder over HTTP:

```
python -m http.server
```
